## Homelab & home automation

My setup runs on Proxmox and NixOS, with Clan for system configuration
and a mix of Docker containers and native services.

Home Assistant handles the home automation, together with MQTT,
Zigbee2MQTT and ESPHome.

Alongside the applications, I work on monitoring, backups and documentation.
